新方案：零 CLI 依赖
核心思路：yaml-cpp 不走 vcpkg 也不走 pip，用 CMake 的 FetchContent 自动下载编译，整个开发环境搭建只需要装一个 Qt。

第一步：安装 Qt（一次性，~30 分钟，下载量 ~400MB）
浏览器打开 https://www.qt.io/download-qt-installer
下载 qt-unified-windows-x64-4.x.x.exe（约 30MB）
运行安装器，注册 Qt 账号（免费），一路 Next 到组件选择页
展开组件树，只勾选两项：

Qt
 └── Qt 6.8.0
      ├── ☑ MSVC 2022 64-bit           ← 包含 Core/Network/Sql/Quick/QML
      └── Additional Libraries
           └── ☑ Qt HTTP Server         ← HttpServer 模块
其它全部取消勾选，完成安装
默认安装到 C:\Qt\6.8.0\msvc2022_64，占用约 1.5 GB。

第二步：yaml-cpp — 不需要手动安装
在项目的 CMakeLists.txt 中加入 CMake FetchContent，首次 cmake --build 时自动从 GitHub 拉取并编译 yaml-cpp，完全透明：


include(FetchContent)
FetchContent_Declare(
    yaml-cpp
    GIT_REPOSITORY https://github.com/jbeder/yaml-cpp.git
    GIT_TAG        0.8.0
)
FetchContent_MakeAvailable(yaml-cpp)
首次构建时 CMake 自动 git clone + 编译，之后增量编译不受影响。

第三步：构建项目（每次开发时的命令）
打开 Developer Command Prompt for VS 2022（开始菜单里搜得到），执行：


:: 配置（首次或修改 CMakeLists.txt 后执行）
cmake -B build -S . -DCMAKE_PREFIX_PATH=C:/Qt/6.8.0/msvc2022_64

:: 编译
cmake --build build --config Release
或者直接在 Visual Studio 2022 中打开 CMake 项目文件夹：VS 自动识别 CMakeLists.txt，在 CMakeSettings.json 中配置 Qt 路径后即可用 IDE 编译调试。
